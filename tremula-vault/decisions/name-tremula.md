# Decision: the name is Tremula

**Decision:** Name the project **Tremula** (from *Populus tremuloides*, the
quaking aspen — the Pando clonal colony: thousands of trunks, one organism,
one shared root system). Fallback on collision: **Osina**.

**Why:** The Pando metaphor maps exactly onto the architecture — many project
vaults (`ramet`/trunks) that are one federated organism (`genet`) sharing
contracts through bridge vaults (`roots`). Name availability was checked: no
collisions in the MCP/dev niche. `Pando` itself is taken (AI coding agent
`digiogithub/pando`); `Engram` has 6+ namesakes; `Mnemo` has 2+.

**Consequences:** Artifacts are `tremula-mcp` (PyPI), the `tremula` CLI, and a
`tremula-vault/` folder at repo root. The aspen terminology (ramet/genet/roots)
is load-bearing across the docs and code.
